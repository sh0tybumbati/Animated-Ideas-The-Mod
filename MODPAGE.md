# GTC's Animated Ideas

Bringing GarrettTheCarrot's community-sourced Minecraft ideas to life, one animation at a time.

GtC's Animated Ideas is a Fabric mod that implements the viewer-submitted features from [GarrettTheCarrot](https://www.youtube.com/@GarrettTheCarrot)'s *"Animating Your Minecraft Ideas"* series - the genuinely useful and (eventually) the gloriously chaotic. Every feature is built to match the spirit of the animation that inspired it.

The mod is released by episode: each update adds the ideas from another part of the series. Everything is individually toggleable through an in-game config screen, so you can run the whole collection or cherry-pick exactly the features you want.

Requirements: Minecraft 1.21(more to come), Fabric Loader, Fabric API, Cloth Config, Mod Menu

Status: Part 1 is fully fleshed out. 
Part 2 is the active episode (4 of 6 features done). 
Parts 3 and beyond are on the roadmap.
